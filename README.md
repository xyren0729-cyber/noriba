# のりば

朝いちばんに開いて、家を出る時刻と遅刻の危険がひと目でわかる発車案内です。スマホでもPCでも使えます。

**サイト**：https://xyren0729-cyber.github.io/noriba/

## できること
- 家を出るまでの秒単位のカウントダウン。授業の開始（または着きたい時刻）から逆算します
- 遅刻の危険度を色で表示（緑 余裕・黄 そろそろ・橙 今すぐ・赤 遅刻）
- 乗換を含む行程と、次の電車
- 同じ行き先に行き方を複数登録すると、その時点でいちばん早いものを自動で選ぶ
- 時間割、天気と気温の推移（予定を重ねたグラフ）、手持ちの服から今日の服、今日の1曲（Spotify アプリで開く）
- 祝日・振替休日・年末年始を判定して、平日と土休日の時刻表を切り替え。学年暦（休み・振替授業・休講）も書ける
- 列車ごとの所要時間（快速は速い、など）で計算。雨の予報の日は徒歩を少し長めに見る
- 授業が終わると「帰り」に自動で切り替え
- 「家を出た」「駅に着いた」「着いた」を押すと、徒歩の見積もりを実際の時間に少しずつ合わせる
- 同じ服が続かない服選び、通学時間に合わせた曲選び
- 気象庁の警報・注意報を表示（大阪市・茨木市）

## 使い方
1. サイトを開き、スマホなら「ホーム画面に追加」する（アプリとして全画面で開き、電波が弱くても起動できます）
2. 「設定」で経路・時刻表・時間割・服・曲を入れる。入力は自動で保存されます（その端末のブラウザの中だけ）
3. 別の端末に移すときは「設定だけコピー」→ 移す先で「貼り付けた設定を読み込む」

天気は [Open-Meteo](https://open-meteo.com/) から取得します。

## iPhone のウィジェット
無料アプリ「Scriptable」を使います。はじめはサイトの「設定」→「ウィジェット・バックアップ」→「ウィジェット用スクリプトをコピー」を押し、Scriptable で「のりば」という名前のスクリプトを作って貼り付けます。設定を変えたら「ウィジェットに送る」を押すだけで反映されます。ウィジェットは出発の10分前・5分前に通知し、JR西日本の遅れも直接確認して、遅れていない行き方を優先します。

## tools/
- `jma_all.py`：気象庁の全国の翌日予報をまとめる
- `jrw_line.py`：JRおでかけネットの区間時刻表から「A駅発 → B駅着」の列車を取り出す
